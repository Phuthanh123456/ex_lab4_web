- Đặt mã nguồn trực tiếp trong `ex1.1_lab4_web`. Dùng Vite, React 19, TypeScript strict và React Router 7.
- Dùng static import cho `PersonDetail` ở bản nền. Chuyển tuyến chi tiết sang import động với skeleton trong `Suspense` ở mốc refactor.
- Dùng điều hướng bàn phím, focus dễ thấy, landmark và thông báo trạng thái tải. Tôn trọng tùy chọn giảm chuyển động.
- Chạy dev server và production build trước khi bàn giao. Giới hạn thay đổi trong Ex1.1. Không tạo AI audit hoặc push. Commit khi được yêu cầu.
